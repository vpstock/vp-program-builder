# vp-program-builder

Victorian Projects program builder. Pick rows from the estimating guideline, enter quantities per area, and get the hours and a program. Saved programs are kept in `data/history.json`.

Hosted with GitHub Pages from the main branch, root folder.

To save from the page, create a fine-grained GitHub token with Contents read and write on this repository only, paste it into the History section and press Save token. The token stays in that browser.
